# ADR-035：统一 Graph Agent runtime

- 状态：已接受（用户确认实施方案）
- 日期：2026-10-14
- 关联：RFC-008、#499、#498
- 后续提议：RFC-009 / PRD-009 增加 Graph v2/v3 隔离与显式选择；尚未实现，原决策保留作历史。

## 背景

旧循环和 Graph 的工具注册、生命周期和执行约束分叉，造成已注册功能在默认聊天中不可用。

## 决策

保留 Graph/Eino 为唯一循环，BaseTool 为统一执行接口；Skill 经适配复用原执行服务。共享协议独立于循环；各调用入口对共同工具目录应用自己的权限过滤。发布回滚依赖上一版镜像，不保留隐式旧循环回退。

## 备选

只补单个工具不能消除结构性分叉；永久维护双循环增加行为兼容成本。两者均不采用。

## 后果

减少重复执行逻辑和维护成本，但需补齐安全 Skill、联网硬开关、动态目录、历史回放及 IM 回归。初始化失败必须显式报告聊天不可用；本次不变更数据库或外部 API。
