# ADR-036：Manager 内置、PAT 鉴权的外部 MCP

日期：2026-10-28。状态：实施。

## 背景与决定

外部 AI 客户端需要查询并操作 Ongrid 资源。现有 MCP 管理页用于连接外部工具，不能承担对外服务。新增独立 `/api/v1/integrations/mcp`，使用官方 Go SDK 的无状态 Streamable HTTP。按请求生成权限目录，复用现有业务服务，禁止导出最终会话 ToolBag。

首期使用用户手动填写的 PAT，不搭建 OAuth 服务。PAT 支持任意未来到期时间及不过期，明文仅展示一次，存储随机 secret 的 SHA-256。编辑允许更新名称、有效期和权限而不更换凭证；删除移除凭证记录，历史操作和审计保留 public ID。每次请求及写入执行前检查当前账号与令牌状态，查询释放结果前再次检查权限。当前资源隔离能力只允许部署管理员接入。

传输无状态不等于写入无状态。复用 Operation 表，新增外部来源、PAT 归属、幂等唯一键、结果及租约字段。Kubernetes 预检查持久化并绑定账号、PAT、规范化参数和版本。新表由既有 GORM 迁移入口管理。

同库资源使用显式 context 事务，资源、操作终态与完成审计一起提交；事务外通知推迟到提交后。远端写入无法加入数据库事务，结果不明时标记 `unknown`，禁止自动重放。完成审计可通过持久标记补写。

## 结果与代价

- 默认关闭入口和写入；不改变现有 JWT 管理接口与内部 Agent 目录。
- PAT scopes 区分读取、修改、删除和执行；管理员也不能越过签发 scopes。
- 成功远端回执不证明服务健康或 Pod 就绪，客户端必须读回验证。
- 多副本共享同一数据库，传输无需粘连；限流仍按实例计算。
- 关闭写入保留原操作查询/取消；已下发动作不能撤回。
- 旧二进制不理解新增状态，回滚前先暂停写入并处理未决操作；不删除新增数据。

独立网关会增加部署与授权维护成本；直接公开内部工具会引入动态工具和聊天状态耦合。采用固定目录与服务端确认：普通资源新建与改名直接执行；删除、重启等高风险写入返回当前操作的直达确认链接，用户确认一次后执行，不要求在审批中心查找。2026-10-29 的 WorkBuddy 外部 MCP 通道实测不支持原生 elicitation，故不依赖客户端弹窗作为强制确认。复用现有 Approval 与管理员权限；链接只是标识，不携带授权，打开页面不会执行。WorkBuddy 配置保持原样。

## 平台 API 扩展

采用经过审查的固定方法/路由清单，通过同进程适配器复用已注册的 protected handlers。仅继承当前 PAT 的管理员身份和 scopes；不允许调用者传 URL、方法、Header，也不公开认证、审批决定和凭据签发/明文读取入口。目录检查要求新增路由明确归类。

含敏感参数的写请求加密保存，Operation 保留密文，dry_run 返回脱敏的参数副本，外部 PAT 不取得解密内容。通用 API 写入不承诺跨服务事务或 CAS；执行中断/异常按 unknown 处理，成功仅表示 API 接受。代价和排除边界见[覆盖说明](../design/external-mcp-coverage.md)。
