# Integration icon sources

These assets are served from this repository so README rendering does not depend on third-party icon APIs. Brand marks remain the property of their respective owners.

The `logos` assets below come from [gilbarbara/logos](https://github.com/gilbarbara/logos), distributed under [CC0](https://github.com/gilbarbara/logos/blob/main/LICENSE.txt). LobeHub assets use the [MIT license](LOBE-LICENSE.md). SearXNG comes from [Simple Icons (CC0)](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). Pyroscope comes from [Grafana Pyroscope](https://github.com/grafana/pyroscope/blob/main/ui/public/icons/logo.svg).

`openai.svg`, `minimax.svg`, `mimo.svg`, and `wecom.svg` reuse the existing marks in [`Provider.tsx`](../../../web/src/components/icons/Provider.tsx). OpenAI and MiMo retain their contrasting badges; MCP and Kimi use a fixed gray in place of `currentColor` so they remain visible as standalone images on light and dark backgrounds. Webhook uses the same gray for its dark paths. SearXNG and MySQL use their blue brand colors; both marks come from Simple Icons (CC0).

The existing Loki, Tempo, OpenTelemetry, Larksuite, DingTalk, and Zhipu assets are unchanged.
