## 实现与边界

- 主助理与 Worker 都有本轮 Skill 目录和 `load_skill`。保留默认/`always`、`keyword`，新增 `on_demand`。Worker 按自身加载情况解析凭据；加载说明不扩大工具权限。
- 资源副本保留所属插件的公共脚本与相对路径。回合和正在执行的审批各持有引用，最后一个引用释放后清理；卸载撤销后续获取。凭据删除/绑定撤销在审批执行时检查。
- MCP 支持工具分页、GET SSE 的列表变更通知及每分钟兜底发现；旧探测不能覆盖更新的探测或配置。临时连接失败保留验证过的工具目录，未变化的后台刷新保留执行句柄。
- 新 v3 MCP 审批固定配置、凭据和工具目录指纹，执行时再检查；旧 v3 无指纹审批需要重新发起。服务禁用后拒绝执行。
- 现有市场安装接口没有原地升级；卸载重装属于撤销。资源副本不跨 Manager 重启续跑。v1/v2 仍未接入执行，设置下拉框禁用这两个选项，避免误导。
