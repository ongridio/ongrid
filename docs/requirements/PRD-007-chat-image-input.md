# PRD-007：聊天图片附件与多模态输入

## 目标

- 支持选择、粘贴、拖入和预览图片，也允许仅发送图片。
- 上传、消息绑定、持久化、历史回放和模型输入形成完整链路。
- 图片不需要公网地址，上游通过 OpenAI 兼容的 `image_url` data URL 接收。
- 图片文件不进入消息 JSON、历史响应和日志。

## 数据与接口

1. 浏览器通过 `POST /api/v1/chat/sessions/{session_id}/attachments` 上传单张图片。
2. Manager 校验会话权限、实际文件类型、大小及像素尺寸，落盘后返回 `attachment_id` 和元数据。
3. 发送消息保留 `content`，通过 `attachment_ids` 引用已上传图片。
4. 用户消息与附件在同一数据库事务中绑定，禁止重复绑定、跨用户和跨会话引用。
5. 历史接口只返回附件元数据；页面通过受鉴权保护的附件读取接口按需加载文件。
6. 模型适配层读取文件并转换成 `image_url` + Base64 data URL；Eino 历史转换必须保留图片。

## 存储和生命周期

- 元数据表：`chat_attachments`，记录会话、消息、所有者、名称、MIME、大小、私有存储路径和过期时间。
- 默认目录：`/var/lib/ongrid/chat-attachments`，可通过 `ONGRID_CHAT_ATTACHMENT_DIR` 修改。
- 正式 Compose 将目录映射到 `ONGRID_DATA_DIR/chat-attachments`，需要纳入备份；多副本部署必须使用共享存储。
- 已发送附件跟随消息和会话保留；删除会话时同时清理附件。
- 未绑定上传的过期时间为 24 小时，上传时触发过期清理。

## 模型能力

- 不要求管理员逐个声明模型是否支持图片，也不根据模型名称猜测能力。
- Ongrid 将完整图片上下文发送给当前选中的模型，由上游模型或兼容网关判断是否支持；不支持时保留并展示上游返回的明确错误。
- 历史中存在图片时，后续纯文本追问仍携带图片上下文，不静默丢弃历史图片。
- 首版仅在 OpenAI 兼容协议适配层发送图片；原生 Anthropic、Gemini 协议后续独立适配。

## 前端交互

- 首页新建会话和会话详情页均支持通过文件选择、拖拽及剪贴板粘贴添加图片。
- 原生文件选择器仅列出 `.png`、`.jpg`、`.jpeg` 和 `.webp`；服务端仍以实际文件内容为准校验，不能只信任扩展名或浏览器 MIME。
- 剪贴板粘贴同时读取 `DataTransferItemList` 和 `clipboardData.files`，兼容 Windows/Chromium 截图工具可能只提供 `items` 的情况。
- 允许不输入文字、仅凭一张或多张图片创建会话并发送首条消息；首页创建会话后，图片继续由新会话的附件接口上传和绑定。
- 待发送图片缩略图显示在输入框圆角容器内部，不在输入框外形成独立卡片。
- 单击待发送缩略图或历史消息图片打开大图预览；预览保持图片比例，可通过关闭按钮、点击遮罩或按 `Esc` 退出。
- 待发送缩略图提供独立删除按钮，点击删除不得触发图片预览。
- 附件校验提示必须跟随当前附件状态更新。因图片数量或合计大小超限产生提示后，用户删除图片使当前附件恢复到限制内时，提示立即清除，无需重新选择图片或发送消息。
- 历史消息图片通过受鉴权保护的接口加载为临时对象 URL，不在页面中暴露公开文件地址。

## 限制

- PNG、JPEG、WebP。
- 每条消息最多 4 张，单张最多 5 MiB，合计最多 20 MiB。
- 组装包含历史图片的上游请求时，累计图片不得超过 20 MiB。
- 拒绝 SVG、伪造 MIME、损坏图片、超大像素图片和重复附件 ID。

## 验收

- 首页和会话页均能通过选择、拖拽和粘贴添加图片；Windows/Chromium 剪贴板截图可以正常识别。
- 从首页仅粘贴图片时，可以创建会话、上传附件并启动模型调用。
- 待发送缩略图位于输入框内部；单击待发送图片和历史消息图片均能打开大图预览。
- 预览可通过关闭按钮、遮罩和 `Esc` 关闭；点击缩略图删除按钮只删除图片，不打开预览。
- 已有 4 张图片时继续添加会显示数量限制；随后删除任意一张，限制提示立即消失，并可继续添加图片。
- 只发图片、图文混发均可成功。
- 发图后继续文字追问，模型仍能读取上下文中的原图。
- 刷新或切换会话后，图片能通过鉴权接口重新显示并继续参与模型上下文。
- 越权读取、跨会话引用、重复绑定均被拒绝。
- 模型调用失败后消息和附件仍可恢复，重试不会重复绑定。
- LLM 设置页无需逐模型勾选图片能力；支持图片的模型可直接处理，不支持的模型由上游返回明确结果。
- 删除会话会清理文件和元数据；未发送附件可过期清理。
- 纯文本聊天行为不变。
