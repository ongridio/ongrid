# PRD-011：外部 AI 的 MCP 资源访问

状态：功能分支实现；真实客户端验收待完成。日期：2026-10-28。

## 用户需求

管理员在豆包工作、WorkBuddy 等客户端手动配置 Ongrid MCP。客户端能按签发权限查询和管理资源。用户可创建 30 天、90 天、自定义到期或不过期的个人访问令牌（PAT），并随时编辑名称、有效期和权限或删除。

## 首期范围

- 设置页创建、列出、编辑和删除当前管理员自己的 PAT；明文只返回一次。
- 远程 Streamable HTTP；PAT 仅用于专用 MCP 路由。
- 设备、主机概况、告警、指标、Kubernetes、日志和链路查询；敏感查询需独立 scope。
- 设备元信息修改及离线设备删除；告警确认、解决和限时静默；规则与面板增删改；白名单服务重启及受限 Kubernetes 动作。
- 普通资源新建和改名无需再次确认。删除、重启等高风险动作先返回直达当前操作的确认链接；具体白名单见设计文档。用户查看目标、参数和风险，确认一次后执行，无需去审批中心查找；Kubernetes 写入仍需一次性预检查。
- 操作 ID、幂等、版本冲突、删除或权限收回后拒绝执行、审计和重启恢复。
- 四套客户端 Skill：告警排查、主机健康、指定对象巡检、资源管理。

当前资源模型不能保证按成员隔离整个部署的通用查询。首期仅接受当前状态有效的系统管理员，授权范围为整个部署。普通成员、OAuth、公共市场发布和任意 Shell 不在本期范围。

## 验收与限制

自动测试须证明：权限过滤与执行一致；不同 PAT 不共享操作；重复键不重复写入；同键不同参数冲突；资源版本变化不被覆盖；本地写入与审计同时回滚；远端超时不自动重放；过期、删除和降权生效；编辑权限后原 Token 继续使用，收回权限阻断在途结果与排队任务；不过期令牌仍可删除。

页面须检查双语、深浅主题和 390/768/1280/1920px。客户端上线验收须记录实际版本、请求来源、握手、查询、普通写入、预检查/操作确认页、幂等、权限修改和删除证据。协议测试与模拟接口页面测试不能替代两端客户端及真实资源验收。

实现与操作说明：[设计](../design/external-mcp.md)、[接入与回滚](../install/external-mcp.md)、[方案取舍](../design/ADR-036-external-mcp-pat.md)。

## 平台能力覆盖扩展

在原有资源工具上增加固定、按 scopes 过滤的 API 目录，尽量覆盖现有产品模块的 JSON 查询和管理能力。新增 API 写入按风险区分；高风险写入、删除及执行在 Ongrid 直达确认页进行一次人工确认；敏感请求加密保存，预览返回脱敏参数。旧 Token 不自动扩大权限。认证、凭据签发/reveal、审批决定、内部入口及不适合 JSON 调用的流式/文件传输接口明确排除，见[能力覆盖](../design/external-mcp-coverage.md)。
