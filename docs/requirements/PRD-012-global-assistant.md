# 全局悬浮助理与页面引用

关联 [Roadmap E.1](../../ROADMAP.zh-CN.md)。本阶段覆盖已登录控制台，包括独立产物查看器。登录页没有助理入口。首页使用主聊天输入框，隐藏悬浮按钮；仍可用快捷键打开之前的浮窗对话。

## 用户路径

1. 点击右下角「AI 助理」或按 ⌘K / Ctrl+K。可拖动入口避开页面数据；桌面也可拖动浮窗标题栏。位置保存在当前浏览器，聚焦入口或桌面标题后可用方向键移动，Home 键复位。默认浮窗以 420 × 650 为基准，按浏览器可用宽高等比例缩放，文字、图标、建议卡和间距随窗体一起缩放。桌面展开态按 690 × 800 等比例适配。手机默认从底部打开，点「展开窗口」可全屏阅读，再点可还原。仅打开不创建会话。
2. 欢迎区有「了解当前页」「下一步排查」两张卡片，点击仅填入问题。展开输入区上方的页面引用，核对本次要附上的字段，或移除后普通提问。有不可传递的筛选时，先确认预览中的范围。
3. 输入框下方可选择本次会话的模型，默认使用 Manager 的默认模型。恢复历史时沿用该会话保存的模型。地球图标控制本次追问是否允许联网搜索，初始关闭。
4. 输入或提交首问后，调查对象固定。收起再打开可继续追问。切换对象或筛选后可以保留原会话，或选择「基于当前页新聊」。
5. 从浮窗顶部的「会话历史」打开已有对话；选中后在浮窗内读取原消息、恢复原引用并继续追问。切换前确认是否放弃未发草稿，取消或读取失败时保留原稿。完整聊天页沿用原会话。断流时可以查看已保存的消息。写操作沿用现有工具权限与审批。

## 各页面提供什么

业务组件通过 `useAssistantPage` 登记自己持有的视图状态。优先使用已经执行的查询、已加载资源的标识及活动标签。没有可用对象时显示状态或让用户选择普通提问。

| 页面 | 代表性字段 |
| --- | --- |
| 事件、资源与诊断 | 告警编号、规则、严重度、状态，设备与 Edge 的独立标识，集群、节点、抓包或报告标识 |
| 可观测性 | 已执行日志查询的绝对时间、设备、服务及级别，链路查询范围，APM 活动视图，拓扑节点和关系数 |
| Agent 工作区 | 会话标识、助理名称、工作流与节点标识、任务类别、技能范围、审批状态、知识列表范围 |
| 管理与设置 | 健康检查结果、升级版本、当前运行时、已配置渠道类型、凭据数量、显示语言和主题 |
| 终端与独立产物 | 连接状态及设备标识，产物 ID 与加载状态。打开 WebSSH 登录框时该弹窗优先接收输入 |

传输范围由每页显式选择。页面不读取整页 DOM、其他标签页、原始日志、SSH 输出、密码框、访问令牌或嵌入产物的正文。

## 接口与会话

现有 `POST /api/v1/chat/sessions` 接受可选 `page_context`，创建响应回显已接受的引用。没有引用的会话使用原协议。示例请求如下。

```json
{
  "title": "这条告警为什么触发？",
  "related_incident_id": 82417,
  "page_context": {
    "page": "告警详情",
    "fields": {"incident_id":"82417","rule":"disk_space_low","severity":"critical"}
  }
}
```

Manager 限制键名、字段数量、值长和整体大小。告警引用必须匹配会话关联 ID，建会话及每轮发问均通过告警服务检查对象可读性。其他页面的字段表示用户看到的快照，实时状态仍由有权使用的工具查询。页面字段不能授予工具权限。

快照存于 `chat_sessions.page_context` 可空列。v2 与 v3 在模型的用户消息中附上快照。数据库保存用户原问题。跨页追问、刷新后从历史继续以及浮窗转完整聊天均使用同一会话引用。旧会话的空列无需回填。先更新 Manager，再更新 Web；旧 Manager 忽略新字段时，浮窗取消本次带引用的请求，提示升级或移除引用。

## 验收入口

- Web 的 `AgentSidePanel.test.tsx` 覆盖建会话、跨页追问、新会话及敏感字段隔离。
- Manager 的 `page_context_test.go` 覆盖输入限制与告警访问检查。
- `go test -tags=e2e ./tests/e2e -run '^TestAssistantPageContext$'` 用 MySQL 和可记录请求的测试模型确认两个版本每轮收到相同引用，历史保留原问题。
