# PRD-008 SMTP 邮件告警通知

关联：#120

## 用户需求

管理员可在「设置 → 通知」创建邮件渠道，用已有邮箱服务向值班人员发送告警，无需额外部署 Webhook 转邮件服务。

## 范围

- 在已有通知页面添加 SMTP 渠道，配置服务器、端口、加密方式、发件人、最多 100 个收件人及可选认证账号和密码。
- 支持 STARTTLS（默认）和隐式 TLS，校验服务器证书；不提供明文认证或跳过证书验证。
- 复用现有密码编辑语义：不回显密码，留空保留，输入 `-` 清除；密码使用既有通知渠道配置存储机制。
- 接入现有测试发送、规则渠道选择、投递记录和重试流程。
- 邮件为 UTF-8 纯文本，包含告警标题、等级、来源和正文，支持中文。

## 验收

1. 管理员可创建、编辑和测试 SMTP 渠道，普通用户不能修改配置。
2. STARTTLS 和 TLS 均能向测试 SMTP 服务投递多收件人邮件。
3. 无效邮箱、端口、头部注入和未知加密模式被拒绝；证书错误、认证失败和服务超时可报告失败。
4. 列表和详情响应不包含 SMTP 密码；编辑不改变密码中的空格。
5. Webhook 和已有 IM 渠道行为不变，明暗主题均可使用。

## 非目标与回滚

不接收邮件，不增加附件、HTML 模板、OAuth2 或邮件服务商专有认证；本次通过通知设置页面配置，不增加环境变量入口。服务端至少需支持 AUTH PLAIN（或允许经过 TLS 的免认证中继）。TLS 证书由系统信任链验证。

回滚代码前停用 SMTP 渠道；已有配置和投递记录保留，无 schema 变更。
