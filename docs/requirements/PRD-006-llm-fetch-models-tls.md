# PRD-006：获取模型列表与自定义模型 TLS 开关

## 背景与范围

LLM 配置目前需要手工录入模型 ID，且自定义 OpenAI 兼容服务使用自签名证书时无法通过连接校验。本功能只处理以下两项，不引入多 Provider 实例：

- 使用当前未保存的地址和密钥从 `/models` 获取模型列表。
- 为“自定义（OpenAI 兼容）”Provider 增加显式的“跳过 TLS 校验”选项。

## 功能要求

- 模型结果去空、去重、排序，最多返回 32 个。
- 空结果或请求失败时保留原草稿。
- 原默认模型仍存在时继续保留，否则选择结果中的第一个模型。
- 获取模型不会自动保存配置。
- 请求期间草稿发生变化时，不允许旧结果覆盖新输入。
- TLS 跳过默认关闭，只允许自定义 Provider 开启。
- TLS 设置必须同时作用于获取模型、测试配置、保存前验证和实际聊天请求。
- 保存键为 `llm.custom_tls_insecure`，无需数据库表结构迁移。

## 安全要求

- `POST /api/v1/integrations/llm/models` 仅管理员可调用。
- 模型查询最多等待 20 秒，且不跟随重定向。
- 不记录、不返回 API Key 或上游原始错误正文。
- TLS 跳过使用 Provider 独立 Transport，不修改进程全局 TLS 行为。
- 页面开启 TLS 跳过后必须展示风险提示，明确仅用于可信内网。

## 验收标准

- 获取模型使用当前页面草稿，而不是数据库中的旧配置。
- 自签名服务默认连接失败，显式启用 TLS 跳过后获取、测试和聊天均可用。
- 命名 Provider 不能开启 TLS 跳过。
- 后端 LLM、setting、integration 测试通过。
- 前端 LLM 页面测试、类型检查和生产构建通过。

## 回退

回退代码即可；新增设置行可保留，旧版本会忽略该键。回退不会修改现有 API Key、Base URL、模型列表或会话数据。
