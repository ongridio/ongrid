# PRD-009：Agent Runtime 版本选择

- 状态：部分基础设施已实现（源码隔离、路由、新会话版本持久化）；管理员版本选择尚未实现
- 日期：2026-10-16
- 优先级：P1
- 关联：RFC-009、PR #503

## 用户目标

管理员可在设置 → AI / Agent 设置选择已发布 Runtime 版本。聊天页不提供选择器；release 默认使用该发布包含的最新稳定版本。

## 建议交互与验收

- v1 固定为首个正式 release v0.7.158 的 Eino Graph；源码已提取，启用前仍需安全、装配和路由验收。
- v2 对应正式发布 v0.18.2 的 Graph 行为，v3 对应当前改进；不是模型版本或 Edge 版本。
- 仅管理员设置提供版本切换。建议设置只影响之后新建的会话，并保留管理员显式配置，避免升级覆盖回退意图。
- 建议旧会话、运行中任务和审批继续归属原版本，新建会话使用切换后的版本。不自动复制待执行动作。
- 升级前的正式发布会话继续使用 v2；非法版本明确报错，不静默切换。
- 两个版本遵守相同的权限和安全底线。未配置模型/工具时如实提示，回退不恢复已撤销权限。
- 测试覆盖所有聊天入口、子任务和审批；版本路由正确率 100%，跨版本执行次数为零。

## 范围与依赖

API、会话持久化、默认设置、管理员设置 UI 与版本路由一起交付，技术设计见 RFC-009。依赖 v2 基线验证、v3 当前审批清理和双版本回归。暂不提供同一会话原地切换、执行恢复或对模型输出完全一致的承诺。

## 风险、计划与复盘

主要风险是共享工具/模型变化导致回退行为漂移、历史数据错误归类、审批跨版本执行。通过版本标记、冻结策略与双版本验收控制。任务拆分和预计里程碑见 RFC-009；发布日期以验收为准。发布后四周内比较各版本工具成功率、用户回退比例与错误率，决定是否调整默认值。
