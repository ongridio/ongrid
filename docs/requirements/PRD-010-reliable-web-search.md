# PRD-010 联网搜索可靠性

状态：已确认，实施中。2026-10-17 用户确认主备来源、错误区分和真实搜索验证方案。

## 问题与目标

测试环境询问 VKE 时 Agent 已正常调用 web_search，但 SearXNG 多个引擎超时。工具丢弃 unresponsive_engines，只返回空结果。Bing 返回 HTTP 200 的空搜索页；百度或搜狗可能触发验证码。仅提高 HTTP 超时无法解决这些问题。

目标：搜索失败不能伪装为没有相关信息；管理员可以配置经验证的主备来源；来源故障不会无限拖住会话；已有工具能力、调用接口和来源引用保留。

## 行为

- 保留 SearXNG、Tavily、Brave 三种来源。默认不新增第三方查询；备用来源必须由管理员显式选择，已有 API key 不等于允许备用查询。
- 搜索结果增加 success、partial、no_results、failed 状态；保留结果、引擎失败和尝试来源。HTTP/解码异常沿用工具错误通道，不转换成正常空结果。返回可用链接时保留结果，不因为部分引擎失败而抛弃。
- 主来源失败或正常空结果时最多尝试一个配置的备用来源；不自动改写查询或向更多供应商广播。模型根据上下文消歧义，引用返回链接；原文读取和内容真实性验证不能仅靠搜索摘要保证。
- 连接/TLS 建立预算 5 秒；单来源默认 20 秒、可配 2–60；总预算默认 45 秒、可配 5–120。上层取消优先。SearXNG 引擎自身的请求预算仍由该服务配置管理。
- 每个进程的来源连续失败 3 次后冷却 1 分钟，下一次需求触发单次恢复探测；没有后台无限重试。成功或正常空结果复位失败计数，来源地址/凭证变化重新探测。进程重启清除健康状态。
- 设置页配置主备、SearXNG 引擎、预算；展示最近一次手动测试成功样例或失败原因。测试查询为 Kubernetes，必须返回有标题的 HTTP(S) 链接。分别验证主备后原子保存完整配置；失败不写入。
- 去除重复链接、拒绝非 HTTP(S) 或缺少标题的结果，最多返回请求数量。不虚构来源或保证稀有查询一定有结果。

## 验收

覆盖全部引擎失败、部分成功、真实空结果、去重、验证码反馈、备用显式授权、请求超时切换、上层取消、冷却恢复、配置变化复位、无密钥备用拒绝保存、管理员权限、失败不部分写入。真实测试环境通过新建临时 Agent 会话验证搜索和官方来源引用，清理验证会话。

浏览器验收覆盖 light/dark、中英文、390/768/1280/1920 宽度；检查新增字段、备用密钥展开、保存和失败展示。

## 边界与后续

免费抓取引擎无法保证长期可用。正式 API 主备仍需管理员提供凭证并从部署环境验收；本次不购买服务、不创建第三方账号。当前健康状态为进程内故障冷却与手动查询探测，不是跨实例持久化健康看板或定时巡检。来源正确性与原文核验另需读取网页能力，本次不把摘要当作原文验证。

## 回滚

代码回退可保留新增 system_settings 行，旧代码忽略新策略；关闭备用恢复单来源行为。测试机 SearXNG 配置修改前备份到 `/opt/ongrid/searxng/settings.yml.before-search-recovery-20261017112118`；恢复该文件为 settings.yml 并重启 ongrid-searxng 即可回滚，但会重新出现原引擎不可用的问题。Manager、Edge、前端镜像不随配置恢复而自动更新。
